# Noto — Электронная тетрадь

Минималистичная, производительная электронная тетрадь для рукописных заметок, лекций, схем, формул и рисования. Работает полностью локально и офлайн, поддерживает десктоп (Windows Electron) и мобильные устройства (Android Capacitor).

---

## 📋 Возможности

- ✍️ **Инструменты письма**: Ручка, карандаш, маркер и ластик с непрерывным сглаживанием сплайнами и поддержкой силы нажатия (`pressure`).
- 📝 **Полноширинный текстовый ввод**: Редактор текста адаптируется под всю ширину страницы, автоматически переносит строки по словам и работает с нулевой задержкой ввода.
- 📐 **Разлиновка листов**: Клетка (5 мм), линейка с полями, точечная сетка, чистый лист. Настраиваемый цвет бумаги (белоснежный, слоновая кость, midnight, графит).
- 🔷 **Геометрические фигуры**: Прямые и пунктирные линии, стрелки, прямоугольники, круги, треугольники, звёзды с автоматическим выравниванием по сетке.
- 📂 **Библиотека тетрадей**: Организация по разделам («Учёба», «Личное», «Проекты»), избранное, дублирование и смена обложек.
- 💾 **100% Локальное и автономное хранение**:
  - **Android**: Нативная локальная база данных SQLite (`@capacitor-community/sqlite`).
  - **Десктоп**: Быстрое локальное хранилище IndexedDB.
  - **Безопасность**: Ваши записи не покидают устройство.
- 📦 **Резервное копирование и перенос**: Экспорт всех тетрадей в единый файл резервной копии и импорт (с добавлением или заменой) для лёгкого переноса между ПК и телефоном.
- 📤 **Экспорт отдельных документов**: Сохранение в PDF, векторный формат `.noto`, изображения PNG и JPEG.

## 🛠️ Стек технологий

- **Фронтенд**: React 19, TypeScript, Tailwind CSS, Lucide Icons, HTML5 Canvas.
- **Десктоп**: Electron, Electron Builder.
- **Мобильная версия**: Capacitor 8, Android SDK, Gradle, SQLite Plugin.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/inderdrag/noto.git
cd noto
npm install
```

### 2. Запуск для разработки

```bash
npm run dev
```

### 3. Сборка десктопного приложения Windows (.exe)

```bash
npm run build
npm run electron:build
```

### 4. Сборка мобильного приложения Android (APK)

```bash
npm run build
npx cap sync android
cd android
./gradlew assembleRelease
```

> ⚠️ **Важно для релизов Android (`versionCode`)**:  
> При каждой публикации новой версии обязательно увеличивайте параметр `versionCode` в `android/app/build.gradle` **на 1** (для версии 1.0.1 установлен `versionCode 5`, для следующей версии укажите `6` и т.д.).  
> Строка версии `versionName` определяется автоматически из `package.json`.

---

> **Примечание по сетевым разрешениям (Offline-first)**:  
> В релизе 1.0.1 приложение работает на 100% локально и автономно, поэтому разрешение `android.permission.INTERNET` удалено из `AndroidManifest.xml`. При добавлении будущей синхронизации через Google Диск разрешение `INTERNET` необходимо будет вернуть.
