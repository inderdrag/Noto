# Архитектура проекта Noto

## Структура каталогов

- **`src/drawing-engine/`**:
  - `math.ts`: Векторная математика, сглаживание сплайнами, расчет пересечений линий ластиком, детекция касания фигур и выделения.
  - `renderer.ts`: Высокопроизводительный движок отрисовки страниц на HTML5 Canvas (штрихи с аппаратным давлением `pressure`, кэшированный адаптивный перенос текста, геометрические фигуры, изображения, сетки).
- **`src/storage/`**:
  - `StorageAdapter.ts`: Абстрактный интерфейс хранилища.
  - `SQLiteStorageAdapter.ts`: Реализация нативного SQLite для Android (@capacitor-community/sqlite).
  - `IndexedDBStorageAdapter.ts`: Реализация IndexedDB для десктопа и веба.
  - `db.ts`: Фасадная точка входа, автоматически переключающая адаптер в зависимости от платформы (`isAndroid()`).
  - `defaults.ts`: Предустановленные шаблоны тетрадей и настройки.
  - `migration.ts`: Нормализация и валидация данных тетрадей и элементов.
- **`src/export/`**:
  - `exporter.ts`: Экспорт и импорт отдельных документов (`.noto`, PDF, PNG, JPG) и полного резервного копирования всей библиотеки.
- **`src/sync/`**:
  - `SyncProvider.ts`: Базовый интерфейс-контракт для будущей интеграции облачного хранилища (Google Диск).
  - `imageStorage.ts`: Локальное кэширование и разрешение изображений.
- **`src/ui/`**:
  - `EditorWorkspace.tsx`: Рабочая область листа тетради.
  - `LibraryView.tsx`: Библиотека тетрадей и разделов.
  - `MenuBar.tsx`: Верхнее системное меню приложения на десктопе.
  - `SettingsModal.tsx`: Окно настроек, переключения тем и резервного копирования.
  - `AboutModal.tsx`: Окно информации о приложении.
  - `ShortcutsModal.tsx`: Справочник горячих клавиш.
  - `editor/InlineTextEditor.tsx`: Изолированный полноширинный текстовый редактор с локальным состоянием, устраняющий задержки ввода.
  - `editor/MobileEditorView.tsx`: Мобильный интерфейс с адаптивными карточками инструментов и навигацией.
  - `editor/PagesSidebar.tsx`: Боковая панель миниатюр страниц.
  - `editor/ToolSidebar.tsx`: Панель параметров пера, толщины и разлиновки.
  - `editor/FloatingToolbar.tsx`: Парящий док инструментов десктопа.
