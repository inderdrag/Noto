ГЛАВНОЕ ПОМНИ:
=====================================

✅ DO:
   • Распаковать tar.gz архив
   • Изменить версию в package.json на 1.0.0
   • Протестировать npm run build
   • Коммитить, тегировать, пушить на GitHub
   • Удалить v1.0.1 через GitHub UI
   • Создать Release v1.0.0 через GitHub UI

❌ DON'T:
   • Не забыть распаковать архив
   • Не забыть поменять версию
   • Не забыть про git push перед тагированием
   • Не забыть удалить v1.0.1
   • Не забыть создать Release (тег ≠ Release!)

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:
=====================================

Откат 1 коммита (до push):
   git reset --hard HEAD~1

Откат после push (новый коммит):
   git revert HEAD && git push origin main

Удалить неправильный тег:
   git tag -d v1.0.0
   git push origin --delete v1.0.0

Удалить неправильный Release:
   GitHub UI → Releases → Edit → Delete release
