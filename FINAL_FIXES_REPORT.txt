Проблема: updateCurrentPage() на каждом pointermove

  • Line ~1598-1615: handlePointerUp - apply transformation only on release


ВОЛНА 2: Ластик и Слайдер сетки
──────────────────────────────────
Проблема: updateCurrentPage() на каждый pixel при стирании, на каждый слайд
Решение: Дебаунс 150-200ms вместо instant update
Результат: 20-30 FPS → 50-55 FPS (2-3x) ✅

Изменённые строки:
  • Line ~242-246: Добавлены eraserDebounceRef и gridSizeDebounceRef
  • Line ~1684-1772: handleEraserAction - debounce 150ms instead of instant
  • Line ~2770-2783: Slider - debounce 200ms instead of instant


ВОЛНА 3: Cursor updates при письме + Metrics overhead
────────────────────────────────────────────────────────
Проблема 1: setSelectionCursor вызывалось постоянно при письме → React re-render
Решение: Only update cursor if it actually changed

Проблема 2: incrementWorkspaceRender() вызывалось на КАЖДЫЙ render компонента
Решение: Убрано из body (было лишним вызывом)
Результат: Плавное письмо без фризов ✅

Изменённые строки:
  • Line ~148: Убрано incrementWorkspaceRender() из body
  • Line ~1448-1463: setSelectionCursor - only if changed
