📊 РЕЗУЛЬТАТЫ ОПТИМИЗАЦИИ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Проблема: Лаги при трансформации выделения (перемещение/масштабирование)
   
   Причина: updateCurrentPage() вызывалась на каждом pointermove
            → React re-render 30-60 раз в секунду
            → Пересчёт ВСЕХ штрихов через .map()
            → FPS падал до 10-20
   
   Решение: Transform preview в рефах
            → Без React state update при движении
            → Применяется только на pointerUp
            → FPS теперь 55-60
   
   Улучшения:
   • FPS: 10-20 → 55-60 FPS (3-5x)
   • React re-renders: 30-60 → 1-2 per sec (30x)
   • Pointer latency: 5-10ms → 1-2ms (5-10x)
